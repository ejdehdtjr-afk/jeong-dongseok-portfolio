# 피디(P.D. · Phishing Defender) — 의심 메시지 5단계 점검

이 앱은 의심스러운 이메일·문자·메신저를 받은 사람이 발신자, 링크, 요청 행동, 압박 표현, 맥락을 차례로 확인하고 안전한 다음 행동을 선택하도록 돕는 정적 웹앱입니다.

## 논문과의 연결

`보안 점검표가 AI의 피싱 메일 분류에 미치는 영향`에서 사용한 다섯 점검 항목을 앱의 실제 점검 흐름으로 구현했습니다. 연구의 작은 공개 표본에서는 점검표 추가의 정확도 향상이 관찰되지 않았으므로, 이 앱은 피싱을 확정 판정하지 않습니다. 대신 사용자가 판단 근거를 빠뜨리지 않도록 돕습니다.

## 실행

자동 메시지 점검은 별도 설치 없이 `index.html`을 브라우저로 열면 됩니다. 전화번호 신고 저장은 공개 배포 URL에서 Supabase 연결을 통해 작동하므로 인터넷 연결이 필요합니다.

## 확인 방법

1. 첫 화면에서 논문 제목과 앱이 누구를 어떻게 돕는지 확인합니다.
2. `의심스러운 배송 문자` 예시를 선택하고 `메시지 자동 확인`을 눌러 위험 신호 및 공식 경로 확인 안내를 봅니다.
3. `일반 일정 안내`를 선택해 안전한 결과 안내를 봅니다.
4. `직접 입력하기`를 선택하고 아무 내용도 입력하지 않은 상태에서 점검 카드 다섯 개를 모두 선택해도 앱이 멈추지 않는지 확인합니다.
5. 화면 아래 신고란에서 가상 전화번호·분류·10자 이상 신고 글을 입력해 저장 흐름을 확인합니다. 같은 번호의 의심 신고가 5건 이상이면 데이터베이스에서 `신고 필요`로 분류됩니다.

## 개인정보·비밀값

메시지 점검 입력은 저장하거나 외부로 전송하지 않습니다. 다만 사용자가 신고 글 저장을 누르면 전화번호·신고 분류·신고 글이 Supabase에 저장됩니다. 예시는 모두 가상 내용이며, 실제 개인정보·비밀번호·인증번호·실명은 입력하지 않아야 합니다. 앱에는 RLS가 적용된 공개 publishable key만 사용하며 DB 비밀번호와 service_role 키는 포함하지 않습니다.

## 자동 확인의 범위

자동 확인은 브라우저 안에서 링크 형식, 민감 정보·금전 요청 표현, 긴급·압박 표현, 텍스트에 드러난 발신자 정보를 찾는 규칙 기반 보조 기능입니다. 맥락은 자동으로 확정할 수 없으므로 항상 `확인 필요`로 표시합니다. 자동 결과는 사용자가 수정할 수 있으며, 피싱 여부를 확정하는 판정이 아닙니다.

## 배포

이 폴더의 파일을 GitHub Pages, Netlify 또는 다른 정적 호스팅에 올리면 로그인 없이 공개할 수 있습니다.
