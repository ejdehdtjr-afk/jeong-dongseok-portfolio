# 중간 점검 2차 제출 순서

1. 목표 문구를 갱신할 경우 목표-입력문구-2차.md를 사용한다.
2. 계획 설계서 영역에 plan.md를 선택해 새 버전 v2를 저장한다. 기존 v1은 유지한다.
3. 중간 점검 2차의 각 입력란에 SUBMISSION-2.md의 동일 제목 아래 본문을 붙여 넣는다.
4. 결과물 URL·소스 URL을 해당 칸에 입력한다. 비교 화면 URL은 확인 방법 또는 제출문에 함께 넣을 수 있다.
5. VERIFICATION-2.md·EVALUATION-2.md와 evidence-2 폴더의 캡처를 첨부한다. 필요하면 evaluation-results.json도 첨부한다.
6. 본인이 직접 사용해 보고 AI·본인의 역할 설명을 검토한 뒤 제출 버튼을 누른다.
