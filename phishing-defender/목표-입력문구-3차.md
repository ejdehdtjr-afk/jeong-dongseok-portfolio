# 목표 화면 입력 문구 · 최종 3차

## 한 줄 소개

의심 문자·메신저의 위험 신호를 이해하고, 이미 행동했다면 상황에 맞는 안전한 다음 단계를 찾도록 돕는 앱

## 누구를 위한 것인가

의심 링크나 인증정보 요청을 혼자 판단하기 어렵고, 링크 클릭·정보 입력·앱 설치·송금 뒤 무엇을 먼저 해야 할지 모르는 일반 사용자

## 핵심 기능 3가지

1. 스크린샷·문자 분석과 의심 문구·실제 주소 표시 2. 상황별 질문과 공식 확인 경로 3. 이미 한 행동별 대응·비식별 요약·신고 상태 조회 및 정정 요청

## 완성의 기준

가상 배송 문자와 정상 안내에서 근거가 재현되고, 행동을 여러 개 선택하면 긴급 조치가 먼저 보인다. 요약에는 원문·주소가 자동 포함되지 않는다. 신고 서버 연결 뒤 접수·조회·정정 요청을 검증하고, 실제 사용자 3~5명이 다음 행동과 상태 문구를 이해하는지 확인한다.

서버 적용·실제 사용자 확인 전에는 해당 항목을 완료로 표시하지 않는다.
