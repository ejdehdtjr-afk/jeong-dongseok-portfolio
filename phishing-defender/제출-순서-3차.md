# 최종 3차 제출 순서

1. 목표 화면 네 칸은 `목표-입력문구-3차.md`의 문구를 입력하고 `plan.md`를 업로드한다.
2. 최종 제출 화면의 문항은 `SUBMISSION-3.md`에서 복사한다. 실제 사용자의 확인 결과가 생기면 해당 항목만 사실에 맞게 수정한다.
3. 결과물 URL은 공개 앱 주소를 넣고, 선택 소스 URL은 저장소의 `phishing-defender` 경로를 넣는다.
4. 증빙에는 `VERIFICATION-3.md`와 `evidence-3/` 이미지를 붙인다. 신고 서버는 2026-11-05 연결을 확인했으며, 실제 사용자 인터뷰는 아직 하지 않았다고 적는다.

제출 화면에서 실제 업로드·제출 버튼은 제출자가 확인한다.
