## 1. 프로젝트 목표

의심 문자·메신저를 받은 사람이 위험 신호를 이해하고, 자신의 상황에 맞는 안전한 다음 행동을 선택하도록 돕는 피싱 예방 웹앱을 만든다.

### 누구를 위한 것인가

의심 문자·메신저의 진위를 혼자 판단하기 어려운 일반 사용자. 특히 메시지 복사와 링크 주소 확인에 익숙하지 않은 사람도 스크린샷을 이용해 점검할 수 있도록 한다.

### 전체 프로젝트 핵심 기능 3가지

1. 스크린샷·텍스트 기반 의심 메시지 점검과 판단 근거 표시.
2. 사칭 유형·사용자 상황별 추가 질문과 공식 확인 경로 안내.
3. 이미 취한 행동에 따른 대응 안내와 결과 요약.

이번 1차에서는 첫 번째 기능을 구현·검증한다. 두 번째와 세 번째는 후속 계획이다.

## 3. 이번에 해결할 문제

기존 앱은 메시지를 직접 복사해야 하고, 어떤 단어가 감지되었는지 원문에서 찾기 어려웠다. 링크를 찾았다는 안내만으로는 실제 접속 호스트를 파악하기도 어려웠다. 1차에서는 입력 부담을 줄이고 분석 근거를 원문과 함께 확인할 수 있도록 한다.

## 4. 1차 구현 범위

### A. 스크린샷 입력과 글자 수정

- PNG·JPEG·WebP 이미지, 10MB·2천만 화소 이하.
- 선택 이미지 미리보기와 한국어·영어 인식.
- 인식 결과를 메시지 입력란에서 수정하고 사용자가 자동 확인을 실행.
- 진행 상태·실패 안내·취소·삭제 제공.
- 빈 이미지·잘못된 파일은 안내하고 직접 입력을 계속 사용할 수 있게 함.

### B. 원문에서 판단 근거 확인

- 민감 정보·금전 관련 표현, 긴급·압박 관련 표현, 링크를 구분해 강조.
- 사용자 입력의 HTML은 실행되지 않도록 이스케이프.
- 메시지 수정 시 과거 결과가 남아 혼동되지 않도록 초기화.
- 단어가 있다고 실제 요구인지까지 확정하지 않으며, 예방·금지 문구의 오탐 가능성을 설명.

### C. 실제 호스트 표시

- URL 파서로 호스트를 구하고, @ 앞 사용자정보와 실제 호스트를 구분.
- HTTP·IP 주소·일부 단축 주소·국제화 도메인 인코딩의 확인 이유 표시.
- 의심 주소는 클릭 가능한 링크로 만들지 않음.
- HTTPS 또는 신호 미검출을 안전 판정으로 표현하지 않음.
- 최종 리다이렉트·악성코드·기관 소유권 검증은 이번 범위에서 제외.

## 5. 구현 방식과 개인정보

기존 HTML·CSS·JavaScript와 GitHub Pages 배포 구조를 이어 쓴다. Tesseract.js 6.0.1의 인식 엔진·WebAssembly·한국어·영어 학습 파일을 같은 사이트에서 제공하고, 이미지 인식은 브라우저에서 수행한다. 메시지·이미지는 앱 서버에 전송하거나 저장하지 않는다. 최초 인식 도구 다운로드에는 인터넷이 필요하며 이미지 선택만으로 원본이 업로드되지 않는다.

기존 전화번호 신고 저장은 사용자가 신고 저장 버튼을 눌렀을 때 Supabase로 전송되는 별도 기능이다. 이번에는 실제 번호 신고를 생성하거나 기존 신고 DB를 변경하지 않는다.

## 6. 1차 확인 방법 — 3단계

1. 결과물에서 가상 문자 이미지를 내려받아 ‘스크린샷 선택’으로 고르고 ‘이미지에서 글자 가져오기’를 누른다.
2. 추출된 한국어·링크를 원본과 대조해 필요하면 수정하고 ‘메시지 자동 확인’을 누른다.
3. ‘오늘 안’, ‘카드 정보’, 링크가 구분되어 표시되고 실제 호스트와 HTTP 확인 이유가 보이는지 확인한다. 입력을 바꾸면 이전 결과가 사라지고 재분석되는지도 확인한다.

- [x] 입력 수정 시 기존 결과와 점검 선택이 초기화된다.

- [x] 이미지 취소·빈 입력·잘못된 파일·좁은 화면 검증 결과를 기록했다.

## 9. AI와 사용자의 역할

- 사용자가 정한 범위: 기존 피싱 앱을 프리미엄 과제로 이어가며, 이번에는 중간 점검 1차와 그에 맞는 plan.md·제출물을 준비한다.
- AI가 수행한 일: 코드 변경, 자동 테스트 작성·실행, 브라우저 기능 확인, 계획서·제출문·증빙 정리.
- 사용자가 제출 전에 할 일: 결과물을 직접 사용해 보고 본인의 판단·수정 내용이 있으면 제출문에 추가한다. AI가 수행한 검증을 본인이 직접 수행한 것으로 바꾸어 쓰지 않는다.
